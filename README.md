# 발음 기관 · 국어 수업용 3D 자료

중학교·고등학교 국어 수업(음운, 발음 기관)에서 쓰는 3차원 발음 기관 자료입니다.
머리를 돌려 보고, **반으로 잘라** 교과서 그림처럼 옆 단면을 보고, 눌러서 한글 이름과 설명을 확인합니다.

- 바로 써 보기: https://speech-organs.vercel.app
- **선생님용 "내 사이트 만들기" 안내**: https://speech-organs.vercel.app/guide/ (코드를 몰라도 순서대로 따라 하면 됩니다)

## 쓰는 법

- 화면 아래 **반으로 자르기**를 누르면 몸 가운데 면으로 잘린 옆 단면이 나옵니다. 얼굴이 왼쪽을 향하는 교과서 그림 방향입니다.
- 단면을 켠 채로 끌어서 돌리면 잘린 면을 여러 각도에서 볼 수 있습니다.
- 부위를 **누르면** 이름과 설명이 나옵니다. 단면에서는 남아 있는 절반만 눌립니다.
- 오른쪽 위 **구조 찾기**에서 `센입천장`, `여린입천장`, `목젖`, `목청`, `혀 전체`처럼 교과서 용어로 찾을 수 있습니다. `성대`, `경구개` 같은 다른 이름으로도 찾습니다.
- **펼치기** 막대를 밀면 부품이 펼쳐집니다. 펼친 동안에는 단면과 피부가 잠시 꺼집니다.

## 소리 내 보기 (발음 시뮬레이션)

화면 아래 **소리 내 보기**를 누르면 오른쪽에 교과서식 자음 체계표와 단모음 체계표가 나옵니다. 글자를 누르면 단면 화면에서 발음 기관이 천천히 움직입니다.

- **자음 19개**: 공기가 올라오고, 목청 상태가 정해지고, 혀나 입술이 막거나 좁히고, 공기가 터지거나 갈리거나 코로 나가는 과정을 네 단계로 보여 줍니다. 거센소리는 더 센 바람으로, 된소리는 목청의 긴장(주황 고리)으로 표시합니다.
- **단모음 10개**: 혀의 높낮이와 앞뒤 위치, 입술 모양, 아래턱 벌림이 바뀌고, 목청이 떨리며 공기가 막힘 없이 입 밖으로 나갑니다.
- 단계마다 자막이 붙고, 오른쪽 목청 그림이 열림·떨림·좁힘·긴장을 보여 줍니다. 속도는 천천히와 보통 중에서 고릅니다.
- 혀나 입술이 막거나 좁히는 순간 그 자리에 **빨간 점**이 뜹니다.
- 목청 둘레의 고리가 목청 상태를 보여 줍니다. 목청이 떨리면(울림) **노란 고리**가 떨리고, 된소리를 낼 때는 **주황 고리**로 긴장을 보여 줍니다.
- 모음을 낼 때는 혀의 기본 자리가 **점선**으로 남아, 혀가 얼마나 올라가고 앞뒤로 움직였는지 비교할 수 있습니다.

움직임은 교과서 설명에 맞춰 만든 근사 동작이며, 실제 MRI 영상만큼 정확하지는 않습니다. 여린입천장은 원본 자료에 겉면이 없어 설명용 모형으로 보여 줍니다.

## 개발

Node.js 22.13 이상이 필요합니다.

```sh
npm ci
npm run dev
```

자료를 다시 만들 때는 `source-data/models`에 원본 전신 자료를 두고 다음을 실행합니다.

```sh
node scripts/build-speech-atlas.mjs --strict
```
