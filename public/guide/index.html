내 사이트 이름 정하기

주소에 들어갈 이름입니다. 영어 소문자, 숫자, 빼기표(-)만 쓸 수 있어요. 예: kim-speech, hanbit-hangul

완성된 앱 파일을 Vercel Drop 화면에 올려 내 주소를 만듭니다. GitHub가 필요 없고, Vercel은 Google 계정으로 가입할 수 있어 가장 덜 막힙니다.
  1. 1

    앱 파일 내려받기

    압축 파일 하나(약 6MB)를 받습니다.

    ⬇ speech-organs.zip 내려받기
    압축을 풀지 마세요. 받은 파일을 그대로 올립니다. 파일은 보통 다운로드 폴더에 저장됩니다.
  2. 2

    Vercel 계정 준비

    Vercel은 내 사이트를 인터넷에 올려 주는 무료 서비스입니다.

    Vercel 계정이 있나요?

    1. 아래 단추로 Vercel을 열어 로그인되어 있는지 확인하세요. 로그인 화면이 나오면 가입할 때 쓴 방법(예: Continue with Google)으로 로그인합니다.
    Vercel 로그인 열기

    아래 순서대로 따라 하면 가입됩니다. (Google 계정 사용, 약 2분)

    1. 아래 Vercel 가입 페이지 열기 단추를 누릅니다. 새 탭이 열립니다.
    2. 맨 위의 Continue with Google을 누릅니다.
    3. 쓰고 있는 Google 계정을 고릅니다. 처음이면 "Vercel에 로그인" 허용 화면이 나오니 계속을 누릅니다.
    4. 사용 목적을 묻는 화면이 나오면 Hobby(개인용, 무료)를 고르고, 이름 칸에 이름을 영어나 한글로 쓴 뒤 Continue를 누릅니다. (이 화면은 나오지 않을 수도 있어요.)
    5. Vercel 첫 화면(대시보드)이 보이면 가입 끝입니다. Git 연결이나 다른 안내가 나와도 누르지 말고 이 페이지로 돌아오세요.
    Vercel 가입 페이지 열기
    Google 계정이 없거나 쓰기 어렵다면

    가입 페이지의 Continue with Email을 누르고 이메일 주소를 넣으면, 그 메일로 확인 코드(숫자)가 옵니다. 코드를 입력하면 가입됩니다. 메일이 안 보이면 스팸함을 확인하세요.

  3. 3

    Vercel Drop에 올리기

    1단계에서 받은 압축 파일을 올리면 1~2분 뒤 사이트가 생깁니다.

    1. 아래 Vercel Drop 열기 단추를 누릅니다. "Drop It. It's Live."라고 쓰인 화면이 열립니다.
    2. 화면 가운데 문장 끝의 파란 글씨 file을 누르고, 다운로드 폴더의 speech-organs.zip을 골라 열기를 누릅니다. (파일을 화면에 끌어다 놓아도 됩니다.)
    3. 프로젝트 이름을 묻는 칸(Project Name)에 kim-speech를 입력합니다. 팀을 고르라고 하면 내 이름으로 된 것을 그대로 둡니다.
    4. Deploy를 누르고 1~2분 기다립니다.
    5. 완성 화면에 나온 주소(…vercel.app)를 누르면 내 사이트가 열립니다. 주소를 복사해 두세요.
    Vercel Drop 열기
    주소는 보통 kim-speech.vercel.app처럼 됩니다. 같은 이름을 다른 사람이 이미 쓰고 있으면 뒤에 글자가 덧붙습니다.
    가입 전에 먼저 올려 보고 싶다면

    로그인하지 않은 채로 Drop 화면에 파일을 올려도 사이트가 바로 만들어집니다. 다만 잠시 뒤 사라지는 임시 사이트입니다. 완성 화면의 Claim your project를 누르고 가입(2단계)까지 마쳐야 내 것으로 남습니다.

🎉 완성! 이제 이 주소를 학생들에게 나눠 주면 됩니다. 사이트 관리는 Vercel 대시보드에서 할 수 있어요.
GitHub(코드 보관함)에 내 앱 코드를 복사해 두고, Vercel이 그 코드로 사이트를 만듭니다. 나중에 코드를 고치면 사이트가 저절로 바뀝니다. 계정이 두 개(GitHub, Vercel) 필요합니다.
미리 알아 두세요. 학교 인터넷에서 여러 명이 동시에 GitHub에 가입하면 GitHub가 스팸으로 보고 막는 일이 있습니다. 가능하면 연수 전에 집에서 가입하거나, 학교에서는 휴대폰 데이터(핫스팟)로 가입하세요.
  1. 1

    GitHub 계정 준비

    GitHub는 코드를 보관하는 무료 서비스입니다.

    GitHub 계정이 있나요?

    1. 아래 단추로 GitHub에 로그인되어 있는지 확인하세요.
    GitHub 로그인 열기

    아래 순서대로 따라 하면 가입됩니다. (Google 계정 사용, 약 3분)

    1. 아래 GitHub 가입 페이지 열기 단추를 누릅니다.
    2. "로봇이 아님을 확인하는 절차" 화면이 먼저 나오면, 화살표 단추를 오른쪽 끝까지 밀어 줍니다. (나오지 않으면 넘어가세요.)
    3. 가입 화면에서 Continue with Google을 누르고, 쓰고 있는 Google 계정을 고릅니다.
    4. 사용자 이름(Username)을 정하라고 하면 영어 소문자·숫자·빼기표(-)로 정합니다. 예: kim-hangul. 이미 쓰는 이름이면 숫자를 붙여 바꿉니다. 나라(Country)를 물으면 South Korea를 고릅니다.
    5. 그림 고르기 같은 확인 퍼즐이 나오면 화면 안내대로 풉니다.
    6. GitHub 첫 화면(Home)이 보이면 가입 끝입니다. 질문 화면(팀 규모, 관심사 등)이 나오면 Skip을 눌러 건너뛰어도 됩니다.
    GitHub 가입 페이지 열기
    Google 대신 이메일로 가입하려면
    1. Email: 자주 쓰는 이메일 주소
    2. Password: 15자 이상, 또는 8자 이상이면서 숫자와 영어 소문자를 섞어서
    3. Username: 영어 소문자·숫자·빼기표(-)
    4. Your Country/Region: South Korea
    5. Continue → 확인 퍼즐 풀기
    6. 메일로 온 숫자 코드를 입력 → 로그인 화면에서 방금 만든 이메일과 비밀번호로 로그인

    메일이 안 오면 스팸함을 보세요. 학교 메일보다 개인 메일이 잘 옵니다.

    가입이 막히면 계정을 새로 여러 개 만들지 마세요. 더 오래 막힐 수 있습니다. 아래 "자주 묻는 문제"를 보고, 오늘은 기본(GitHub 없이) 방법으로 진행해도 됩니다.

    Vercel 계정 준비

    심화 과정에서는 Vercel을 GitHub와 연결해서 씁니다.

    Vercel 계정이 있나요?

    1. 아래 단추로 Vercel에 로그인되어 있는지 확인하세요.
    2. 기본 과정에서 Google로 가입했다면 그대로 써도 됩니다. 다음 단계에서 GitHub 연결을 한 번 더 허락하는 화면이 나옵니다.
    Vercel 로그인 열기

    GitHub 계정으로 가입하면 연결까지 한 번에 됩니다. (약 2분)

    1. 먼저 1단계의 GitHub에 로그인되어 있어야 합니다.
    2. 아래 Vercel 가입 페이지 열기 단추를 누르고 Continue with GitHub를 누릅니다.
    3. GitHub 화면에 "Authorize Vercel"이 나오면 초록색 Authorize Vercel 단추를 누릅니다.
    4. 사용 목적을 묻는 화면이 나오면 Hobby(개인용, 무료)를 고르고 이름을 쓴 뒤 Continue를 누릅니다.
    5. Vercel 첫 화면(대시보드)이 보이면 가입 끝입니다. 이 페이지로 돌아오세요.
    Vercel 가입 페이지 열기
  3. 3

    버튼 하나로 내 저장소 만들고 배포하기

    원본 코드를 내 GitHub에 복사하고, Vercel이 바로 사이트를 만듭니다.

    ▲ Vercel로 내 저장소 만들고 배포하기
    1. Vercel의 "New Project" 화면이 열리고 Cloning from GitHub · Byeongeo/speech-organs가 보이면 제대로 온 것입니다. "Sign in to clone and deploy"라고 나오면 2단계에서 가입한 방법으로 로그인합니다.
    2. Create Git Repository(저장소 만들기) 부분에 GitHub 단추가 보이면 눌러 연결합니다. GitHub 화면이 나오면 Install(또는 Authorize)을 누르고, 저장소 범위를 물으면 All repositories를 그대로 둡니다.
    3. 저장소 이름(Repository Name)이 kim-speech인지 확인하고 Create를 누릅니다.
    4. 자동으로 만들기(Building)가 시작됩니다. 2~3분 기다리면 축하 화면(Congratulations)이 나옵니다.
    5. 화면의 사이트 그림이나 Continue to Dashboard → Visit을 누르면 내 사이트가 열립니다.
    화면의 영어 문구는 Vercel이 바꾸면서 조금 다를 수 있어요. 비슷한 단추를 누르면 됩니다.

    나중에 고쳐 쓰기

    이제 내 GitHub에 코드가 있습니다.

    1. GitHub의 내 저장소에서 파일을 고치고 저장(Commit)하면, Vercel이 알아서 1~3분 안에 사이트를 새로 만듭니다.
    2. 설명 문장을 바꾸거나 기능을 더하고 싶으면, Claude 같은 AI 도구에 "이 저장소에서 ○○을 바꿔 줘"라고 부탁해 고칠 수 있습니다.

자주 묻는 문제

GitHub 가입 중 "We couldn't create your account" 같은 오류가 나요

학교처럼 여러 사람이 같은 인터넷을 쓰는 곳에서 자주 생깁니다. 휴대폰 데이터(핫스팟)로 바꾸거나, 다른 브라우저 또는 시크릿 창에서 다시 해 보세요. 조금 기다렸다가 다시 해도 됩니다. 계정을 새로 여러 개 만들면 더 막힐 수 있으니 피하세요. 그래도 안 되면 오늘은 기본(GitHub 없이) 방법으로 진행하세요.

GitHub 계정이 정지(suspended)됐다고 나와요

같은 인터넷에서 한꺼번에 가입해 스팸으로 잘못 걸린 경우가 많습니다. 새 계정을 만들지 말고 GitHub 지원(support.github.com)에 문의하면 며칠 안에 풀리는 경우가 많습니다. 그동안은 기본 방법으로 진행하세요.

"로봇이 아님을 확인" 화면이 계속 나와요

화살표를 오른쪽 끝까지 천천히 밀어 주세요. 계속 반복되면 그 인터넷 주소가 의심받고 있는 경우입니다. 휴대폰 데이터로 바꿔 보세요.

확인 메일(숫자 코드)이 안 와요

스팸함과 프로모션함을 확인하세요. 학교 메일은 걸러지는 경우가 있어 개인 메일이 더 잘 옵니다. 가능하면 Google 계정으로 가입하면 이 단계가 없습니다.

GitHub에서 2단계 인증(2FA)을 켜라는 메일이 왔어요

코드를 올린 계정에 GitHub가 보내는 안내입니다. 메일을 받은 날부터 45일 안에 설정하면 됩니다. 휴대폰 인증 앱(Google Authenticator 등)이나 패스키로 설정합니다.

Drop에 올렸는데 화면이 안 열리거나 오류가 나요

압축을 풀어 폴더째 올리지 않았는지 확인하세요. 받은 speech-organs.zip 파일을 그대로 올려야 합니다. 학교 인터넷이 느리면 올리는 데 1분 넘게 걸릴 수 있습니다.

내려받기 단추를 눌러도 파일이 안 받아져요

학교 컴퓨터 보안 설정 때문일 수 있습니다. 다른 브라우저(크롬, 엣지, 웨일)로 이 페이지를 열어 다시 시도하거나, 학교 정보 담당 선생님께 문의하세요.

사이트 주소 이름을 바꾸고 싶어요

Vercel 대시보드에서 내 프로젝트 → Settings → Domains에서 …vercel.app 주소를 바꾸거나 더할 수 있습니다.
